# Aether Song

Browser whale-song generator in the Aether series. Mournful cries for dark ambient source, with octave, level, dry / echo / hall, and a mono or stereo 24-bit 48 kHz WAV export.

**Play:** open `index.html` in Chrome, Edge, or Safari. On a phone, use the same file. Compose, then Replay to hear the same take. Download the WAV for the DAW.

**Space:** Off is a dry cry. Echo is three same-polarity repeats. Hall is a mono tail. Stereo keeps the dry signal identical on both sides. Mono is a true one-channel file.
